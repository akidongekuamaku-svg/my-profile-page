# Personal Profile Webpage

## About the Project

This project is a simple personal profile webpage created as part of my web development and Git/GitHub assignment.

The webpage introduces me, my skills, my goals and my contact information.

## AI Tool Used

I used ChatGPT to help me create and improve the webpage.

## How AI Helped

ChatGPT helped me generate the initial HTML structure and CSS styling. It also helped me improve the webpage structure, add a profile image, create a navigation menu, make the webpage responsive on mobile devices and fix errors.
